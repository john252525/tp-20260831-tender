# Iteration 008 — Скрипт и справочник деплоя
Date: 2026-09-17

## Goal
Деплой проекта был слабо документирован и требовал ручных шагов.
Сделать автоматизированный скрипт плюс подробный справочник.

## Changes
- scripts/deploy.sh — идемпотентный деплой: проверки Docker и места,
  генерация секретов в .env, валидация незаполненных секретов, проверка
  сервиса эмбеддингов, сборка образов, запуск, ожидание Postgres и Backend
  и Frontend, создание первого API-токена, отчёт с адресами
- docs/DEPLOY.md — быстрый путь, таблица действий скрипта, ручной путь,
  структура сервисов, деплой изменений кода, бэкап БД, подключение
  внешних эмбеддингов, типовые проблемы, диагностика
- .env.example в корне — 37 строк, все переменные с пояснениями

## Tests
