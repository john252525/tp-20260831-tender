# GLOSSARY

Доменные термины, чтобы не путаться.

## Закупки

- **Тендер** — закупка из ЕИС, импортированная через ГосПлан API
- **НМЦК** — начальная (максимальная) цена контракта, стартовая цена закупки
- **Лот** — связка тендера и поставщика (таблица lot_suppliers),
  по одному тендеру может быть несколько лотов
- **Позиция закупки** — товарная строка тендера с наименованием, характеристиками,
  ОКПД2 и количеством (tender_positions)
- **ОКПД2** — классификатор продукции, код вида 32.50.50.190
- **КТРУ** — код товара, работы, услуги (справочник ЕИС)
- **ЕИС** — Единая информационная система в сфере закупок

## Документы и извещения

- **Извещение** — документ закупки в ЕИС, содержит состав закупки
- **notificationInfo** — блок детального ответа ГосПлан с составом закупки
  (позиции, документы, условия, заказчик)
- **attachmentsInfo** — блок с файлами документов закупки
- **44-ФЗ / 223-ФЗ** — законы о закупках, у ГосПлан отдельные разделы API

## Коммерческие предложения

- **КП** — коммерческое предложение от поставщика (commercial_offers)
- **Coverage** — доля позиций тендера, закрытых ценами в КП (процент)
- **Маржа** — разница между НМЦК и ценой поставщика; абсолютная и в процентах
- **Себестоимость** — закупочная цена; сейчас НЕ вводится, маржа считается от НМЦК
- **match_type** — соответствие позиции КП позиции тендера:
  exact (точное), analog (аналог), not_found (нет)
- **clarification_items** — список недостающей информации в КП

## Коммуникации

- **cp_request** — запрос КП поставщику
- **cp_response** — ответ поставщика с КП
- **clarification** — запрос уточнений по неполному КП
- **reminder** — напоминание не ответившему поставщику
- **discount_request** — запрос улучшения цены (торг)
- **NO_RESPONSE** — статус лота, ответ не пришёл дольше response_timeout_hours

## Технические

- **Эмбеддинг** — вектор текста (768 чисел) для семантического сравнения
- **pgvector** — расширение PostgreSQL для хранения векторов
- **Семантический фильтр** — сравнение вектора тендера с векторами категорий
  косинусным сходством: RELEVANT (0.75+), UNCERTAIN (0.60+), NOT_RELEVANT
- **Скор** — итоговая оценка тендера: маржа, простота, объём, конкурентность
- **Конвейер** — автоматический цикл обработки тендера (pipeline_service)
- **Черновик** — подготовленное письмо поставщику (outgoing_drafts), ждёт отправки

## Тестирование

- **jsdom** — среда для тестов без браузера: быстро, но не воспроизводит память
  и реальный рендеринг, тяжёлые страницы не ловит
- **Playwright** — запуск реального браузера в тестах; работает только с хоста,
  в alpine-контейнере нельзя (musl против glibc)
- **chrome-headless-shell** — облегчённый браузер для тестов; полный chromium
  на больших таблицах падает по OOM
- **E2E** — проверка сквозного сценария в реальном браузере на живом стенде
