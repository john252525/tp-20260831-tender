## Приоритет 1: влияет на бизнес-результат

### Автоотправка черновиков писем
- **Проблема:** конвейер генерирует черновики автоматически (сейчас около 240
  в статусе draft), но отправка — ручной шаг через UI (POST /tenders/{id}/drafts/send)
- **Влияние:** главный затор воронки: письма готовы, но не уходят
- **Решение:** либо автоотправка по расписанию, либо подтверждение человеком
  (требует согласования с заказчиком — это внешнее действие, письма реальным людям)

### Учёт себестоимости
- **Проблема:** маржа считается как НМЦК минус цена поставщика. Закупочная цена
  (себестоимость) нигде не вводится
- **Влияние:** «лучшие по прибыли» ранжируются по валовой марже, а не по чистой
- **Решение:** добавить поле себестоимости на позицию или категорию, учесть в скоринге

### Разгрести тендеры в ERROR
- **Проблема:** около 1019 тендеров в ERROR, из них большинство — «Нет текста для
  семантического анализа» (наследие: импортированы до появления разбора состава закупки)
- **Текущее:** восстановление идёт порциями по 20 раз в 30 минут
  (reprocess_unenriched_tenders_task). При таком темпе — несколько суток
- **Решение:** разовый массовый прогон
